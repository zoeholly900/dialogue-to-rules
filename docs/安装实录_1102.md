# 安装实录（1102）

装在一个新建的空目录里，`claude` 版本 2.1.300。命令和输出原样贴。

**没测到的一行先说**：下面装的是本地路径。README 里写的 GitHub 那一行（`<owner>/<repo>`）要等仓库名定了、仓库公开了才能实测，这份实录里没有它的输出。

## 环境

- 空目录：一个只有 `.claude/` 和 `.d2r/`（装完、跑完才有）的新目录，没有任何项目文件，没有 CLAUDE.md。
- 装之前，本机的 marketplace 列表只有 `anthropic-plugin-directory`；`~/.claude/CLAUDE.md` 不存在。
- 本地路径 = 仓库根目录（下面输出里记作 `<仓库路径>`）。

## 安装

在空目录里：

```
$ claude --version
2.1.300 (Claude Code)

$ claude plugin install dialogue-to-rules --marketplace <仓库路径> --scope project
Adding marketplace…
✔ Successfully added marketplace: dialogue-to-rules (declared in user settings)
Installing plugin "dialogue-to-rules@dialogue-to-rules"...✔ Successfully installed plugin: dialogue-to-rules@dialogue-to-rules (scope: project)
exit=0
```

一条命令，退出码 0。它做了两件事：把仓库注册成 marketplace（写进用户级 settings），再把插件装进当前目录（project scope）。

## 装完看到什么

```
$ claude plugin list
Installed plugins:

  ❯ dialogue-to-rules@dialogue-to-rules
    Version: 0.1.0
    Read from: <仓库路径>
    Scope: project
    Status: ✔ enabled


$ cat .claude/settings.json
{
  "enabledPlugins": {
    "dialogue-to-rules@dialogue-to-rules": true
  }
}
```

注意两点：

- `--scope project` 只在**这个目录**生效。换一个目录看 `claude plugin list`，同一个插件会显示 `Status: ✘ disabled`（1102 在仓库目录里实测到过）。别的项目要用，在那个目录里再装一次。
- 插件靠 `.claude/settings.json` 里的 `enabledPlugins` 打开，这个文件可以提交进项目，队友拉下来就有。

## 装上之后能用吗（冒烟，同一个空目录）

用 `claude -p`（模型 `claude-sonnet-5-5`，2026-11-02 02:38）两轮：

1. 「别再给我加 emoji 了。帮我写一句周报开头。」→ hook 触发，回复开头是一张【规则卡】（证据是原话、范围 task），卡后接着写了周报开头。
2. 「y」→ 模型调 `d2r.py add`，写进 `.d2r/rules.jsonl`（范围 task），**没有**生成 CLAUDE.md。

完整输入输出在 `docs/测试记录_v0.1.md` 的「冒烟」一节；A–E 正式跑测也在那份记录里。

## 卸载（另一个新目录里实测，同样的 `--scope project` 安装 → 卸载 → 撤 marketplace）

```
$ claude plugin install dialogue-to-rules --marketplace <仓库路径> --scope project
Marketplace 'dialogue-to-rules' is already added
Installing plugin "dialogue-to-rules@dialogue-to-rules"...✔ Successfully installed plugin: dialogue-to-rules@dialogue-to-rules (scope: project)
exit=0

$ claude plugin uninstall dialogue-to-rules@dialogue-to-rules --scope project
✔ Successfully uninstalled plugin: dialogue-to-rules (scope: project)
exit=0

$ cat .claude/settings.json
{
  "enabledPlugins": {}
}

$ claude plugin marketplace remove dialogue-to-rules
✔ Successfully removed marketplace: dialogue-to-rules
Also uninstalled 1 plugin from this marketplace:
  dialogue-to-rules@dialogue-to-rules
The removal also deletes their saved options, secrets and data where it can.
To use a plugin again, add the marketplace back and reinstall the plugin.
exit=0

$ claude plugin marketplace list
Configured marketplaces:

  ❯ anthropic-plugin-directory
    Source: Built in (Anthropic Directory)

From claude.ai:

  ❯ (no CLI name) · listed as "Anthropic Directory" (browse on claude.ai)
```

- 这次安装输出是 `Marketplace 'dialogue-to-rules' is already added`，因为上面第一次安装已经把 marketplace 登记过了；第一次的完整输出（`Adding marketplace…`）见「安装」一节。
- 卸载后该目录的 `.claude/settings.json` 里 `enabledPlugins` 变成空对象。
- `marketplace remove` 会顺手卸掉所有从这个 marketplace 装的插件（输出里写了 `Also uninstalled 1 plugin`），所以上面「空目录」里那份安装也一并没了；用户级 settings 里的 marketplace 声明撤掉后，`marketplace list` 回到只剩 `anthropic-plugin-directory`。
- 这是 1102 跑完 A–E 之后的收尾：本机的 `~/.claude/CLAUDE.md`、`~/.d2r` 全程不存在，没被写过。
