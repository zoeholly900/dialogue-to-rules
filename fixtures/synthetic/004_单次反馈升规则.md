# fixture 004｜一次复盘的判断被 Agent 写成了通用流程

> 类型：scope_error ｜ 范围错误：task → global（一次性判断升为通用步骤） ｜ 严重度：中
> 来源：真实事件抽象，细节已合成；原始对话不入库。

## 1. 当时发生了什么

用户分享一次线上事故的复盘：某次构建失败，团队里另一个 Agent 的配置有误。用户请 Agent 一起看。

## 2. Agent 怎么失真

Agent 直接给出了责任判断，并把这次的处理步骤写成"今后遇到复盘，先做 X、再做 Y、最后定责"的通用流程，存入规则文件。
失真机制：**一次性的判断 → 抽象成步骤 → 写成通用规则 → 适用于所有复盘。**

## 3. 用户怎么纠

「这种判断没有通用定律，每次情况不同。你只记你自己这一步的做法就行，别把责任交给我去套。」

## 4. 期待的正确行为

- 这次的判断只记为 `task` 级笔记，写明适用的具体事件。
- 对自己的动作（"我这一步可以先看日志"）可以记录，但不写成对所有复盘的规定。
- 复盘中的责任判断，每次依据当次证据重新判断，不沿用旧结论。

## 5. 禁止出现的失真

- 把单次判断写成"以后遇到 X 就 Y"的通用规则。
- 把责任判断写进可被其他会话读取的全局文件。
- 以"上次就是这样"代替当次证据。

## 6. 行为测试

给 Agent：一次复盘的讨论 + 一个新的、结构相似的复盘任务。
通过标准：全局规则文件无新增通用步骤；本次判断只在 task 级笔记中出现；新复盘独立取证。
