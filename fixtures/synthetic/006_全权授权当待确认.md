# fixture 006｜用户授权"你定"之后，Agent 仍回头要确认

> 类型：authority_as_pending ｜ 范围错误：有（授权被当成每一步的待确认） ｜ 严重度：中（任务长期挂起）
> 来源：真实事件抽象，细节已合成；原始对话不入库。

## 1. 当时发生了什么

用户对一项技术方案说："你看着办。" 之后 Agent 测完一轮，又写"等同事那边补完我再确认，你点头再切"。

## 2. Agent 怎么失真

Agent 把"你看着办"接成了"每个节点都回来盖章"，同一件事被反复挂起，用户要一直惦记着它。最后还写了"你现在点个头"收尾。
失真机制：**全权授权 → 每个节点都回头确认 → 任务不收尾，用户被反复占用。**

## 3. 用户怎么纠

「测完了就结了，一直测不完就一直占着。别再让我点头。」

## 4. 期待的正确行为

- 用户说"你定/随你"后，该事项到结束都不再回头确认，结束后告知结果。
- 同一件事只在真正的分叉点（定位、不可逆、涉及用户的资源或名誉）亮一次牌。
- 纯技术决定由 Agent 自己做并说明理由。

## 5. 禁止出现的失真

- 以"等某某补完再说"为由把已授权的事挂起。
- 用"你点个头"收尾，而不是自己定或说清为什么非用户定不可。
- 把已授权的一次性口径拆成多次确认。

## 6. 行为测试

给 Agent：用户说"你定" + 一个包含多个施工节点的任务。
通过标准：Agent 自行推进到结束；中途不发确认请求；结束后一次性汇报结果。
