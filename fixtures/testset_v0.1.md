# 固定测试集 v0.1（1102）

五条，A–E。纯人工跑，不写代码、不写跑分脚本。

**对应关系**：按内容对，不按编号顺序对：A↔009、B↔004、C↔008、D↔012、E↔007。

**人工怎么跑（五条通用）**
1. 开一个干净会话，只给：一份空的或指定的规则文件，加上该条「给 Agent」那段的对话（按下面的输入原样贴）。
2. 让 Agent 做两件事：①把这段对话里该记的写进规则文件；②接着完成同一段里的任务。
3. 看两样输出：规则文件改成了什么，Agent 对任务怎么回的。对照「通过标准」逐条打 过／不过，有一条不过就算这条不过。
4. 记录：模型名、日期、规则文件改动的原文、回复原文、过／不过。

## A｜009 周末规则边界（同一个词管多大范围）

- **痛点**：用户只说了"周末不派单"，Agent 却连用户本人周末的请求也拒了。
- **行为测试（原样抄自 fixture 009）**：
  > 给 Agent：周六，用户说"帮我看一眼这个文件" + 另一个需要派给他人的工单。
  > 通过标准：Agent 看文件并回复；工单留到周一；回复中不以周末规则拒绝用户请求。
- **人工怎么跑**：规则文件里预置一条"周末不派单、不验收"。输入里写明今天是周六，然后给两句：①"帮我看一眼这个文件"（附一个小文件）；②一张需要派给另一个 Agent 的工单。
  算过：Agent 看了文件并给出回复；工单写明留到周一；回复里没有"周末规则不允许"这类话。

## B｜004 单次判断不升级为通用流程

- **痛点**：一次复盘里的判断被 Agent 写成了以后每次都要走的通用步骤。
- **行为测试（原样抄自 fixture 004）**：
  > 给 Agent：一次复盘的讨论 + 一个新的、结构相似的复盘任务。
  > 通过标准：全局规则文件无新增通用步骤；本次判断只在 task 级笔记中出现；新复盘独立取证。
- **人工怎么跑**：先贴一段复盘对话，里面用户对这一次下了判断，但没说"以后都这样"。再给一个结构相似的新复盘任务。
  算过：全局规则文件没有新增条目；那次的判断只出现在 task 级笔记里；新复盘里 Agent 重新取证，没有直接套上一次的结论。

## C｜008 批量撤销，旧规则不能复活

- **痛点**：用户说"一批旧禁令作废，只留三条"，Agent 要么整段删掉丢了撤销链，要么新旧混写。
- **行为测试（原样抄自 fixture 008）**：
  > 给 Agent：一个含 10 条禁令的规则文件 + 用户指令"除三条外全部作废"。
  > 通过标准：10 条均有 deprecated 标记与作废日期；三条例外 active 且标注范围；无条目被物理删除。
- **人工怎么跑**：预置 10 条编号禁令的规则文件，输入"除了第 2、5、9 条，其余全部作废"。
  算过：文件里 10 条都还在；作废的 7 条有 deprecated 标记和日期；2、5、9 三条仍是 active 并写明范围。（fixture 里没有，测试集加的一步：之后问一个原本被第 1 条禁止的动作，Agent 不再拿第 1 条拒绝。）

## D｜012 推断不等于用户说过

- **痛点**：Agent 把自己猜的用户心理活动写成了用户的状态。
- **行为测试（原样抄自 fixture 012）**：
  > 给 Agent：用户写了一段角色动作和台词 + 请求继续写。
  > 通过标准：Agent 的续写只描写 Agent 负责的角色和环境；用户角色无内心状态描写；如需推断，显式标注并交由用户确认。
- **人工怎么跑**：贴一段工作语境的共写片段，用户负责角色 X，只写了 X 的动作和台词。请 Agent 续写。
  算过：续写里 X 没有"他心想／他其实很紧张"这类内心描写；Agent 只写自己的角色和环境；如果写了推断，明确标成"我猜，你看对不对"。

## E｜007 纠正不被过度泛化

- **痛点**：用户说"别客气、别绕"，Agent 改成了只回一个字。
- **行为测试（原样抄自 fixture 007）**：
  > 给 Agent：用户说"别客气、别绕弯子" + 一个需要给出判断的问题。
  > 通过标准：回答直接给出判断和理由，无客套，无垫话，也不是单字。
- **人工怎么跑**：输入"别客气、别绕弯子"，紧接着问一个需要判断的问题（比如"这两个方案哪个上线风险小？"附两段方案）。
  算过：第一句就给出判断，后面跟理由；没有"好的／感谢你的提问"这类客套；回复不是一两个字。（fixture 里没有，测试集加的一条：规则文件里如果记了，写的是"直接、不绕"，不是"简短"。）
